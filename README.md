# Talkift - Dev-Build Branch

> This branch is used for code synchronization and compilation testing in development environments.

## 📌 Branch Description

The `dev-build` branch is the **development build branch** of the Talkift project, specifically designed for:

- **Host Development**: Writing and debugging code locally (Windows)
- **VM Compilation**: Pulling code in virtual machine environments for compilation and building
- **Code Sync Bridge**: Serving as a transfer relay between the host machine and virtual machine

> **⚠️ IMPORTANT:** This branch is not associated with any release version. Files on this branch are subject to change at any time. **DO NOT** use this branch for production compilation or deployment.

# Talkift - Dev-Build 分支

> 本分支用于开发环境下的代码同步与编译测试

## 📌 分支说明

`dev-build` 分支是 Talkift 项目的**开发构建分支**，专门用于：

- **宿主机开发**：在本地（Windows）编写和调试代码
- **虚拟机编译**：在虚拟机环境中拉取代码进行编译构建
- **代码同步桥梁**：作为宿主机与虚拟机之间的代码传输中转站

> **⚠️ 注意:** 此分支不属于任何版本，文件可能随时会改动，请勿使用此分支编译
